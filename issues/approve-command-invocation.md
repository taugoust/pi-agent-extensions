# Offer command-invocation-wide AgentSH approval

## Status

In progress.

## Problem

Pi currently offers one-shot target approval and several session scopes, but no explicit way to accept every AgentSH approval request generated by one top-level Bash invocation.

## Desired behavior

- Render AgentSH's command-wide scope as “Allow all requests for this command invocation”.
- Send it as a command-scoped (`once`) target rather than a session grant.
- Do not offer an equally broad denial unless separately designed.
- Keep the safe default on one-shot denial.
- Test choice rendering and the exact resolution payload.
